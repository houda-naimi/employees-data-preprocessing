# Employees Dataset Preprocessing and Cleaning

## Project Overview
This project focuses on preprocessing and cleaning a dataset containing heterogeneous employee data, including both numerical and categorical attributes.

The project was completed using **Python**, **Pandas**, and **Scikit-learn** in Google Colab.

---

## Dataset Information

- Dataset file: `employees.csv`
- File type: CSV

### Dataset Attributes

The dataset contains the following attributes:

- duration
- wage-increase-global
- wage-increase-first-year
- wage-increase-second-year
- working-hours
- standby-pay
- delay-hours
- education-allowance
- statutory-holidays
- vacation
- teleworking
- contribution-to-dental-plan
- bereavement-assistance
- contribution-to-health-plan
- class

---

## Tasks Completed

- Load dataset
- Show dataset information
- Display first rows
- Detect duplicates
- Remove duplicates
- Remove redundant columns
- Handle missing values
- Perform statistical analysis
- Apply Linear Regression imputation
- Detect and handle outliers using IQR
